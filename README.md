# Eric’s website

Static personal website using self-hosted Geist Sans.

## GitHub Pages

Create a public repository named `ericyenn.github.io` under `ericyenn` and upload this folder’s contents to its `main` branch. In Settings → Pages, choose “Deploy from a branch”, `main`, and `/ (root)`. The site will appear at https://ericyenn.github.io once deployment completes.

Edit `index.html` for the introduction, `blog.html` for posts, `projects.html` for projects, and `style.css` for styling. No build step is required.
